# 沉淀经验

仅从当前可读取的对话、资料与成果提取反馈；其他聊天不会自动可见。区分用户原话、最终确定内容与 AI 的推测。结合最终稿及修改过程，提出精简的候选经验，标明来源、日期、适用范围（本次、项目、某类任务或通用）、原因及待确认状态。

一次性要求不要自动推广为长期偏好。向用户展示候选并取得确认后，才把长期经验写入已确认记录或建议更新相关 Skill、模板；若用户要求更正或撤销，保留可追溯的变更历史。实际成果和原始资料保持原样，规则冲突时以当前明确指令及适用范围为准。

若用户已经明确确认某条经验及范围，可直接记录该条；无法确定范围时先标待确认。下一次同类任务检索已确认的经验，并根据新反馈继续调整。
