# 验收标准与证据

本清单借鉴 NIST AI 风险管理框架、OWASP 提示注入与 RAG 安全指导、CISA 备份建议，指标是本项目的工程验收目标，不代表官方认证。每次重要修改后重新执行测试并记录日期、版本、环境和结果。

## 本地基础能力

| 验收项 | 通过条件 | 证据 |
| --- | --- | --- |
| 初始化和保存 | 重复初始化不覆盖原始资料；输入和附件可读；错误有明确提示 | 自动化测试与临时目录实测 |
| 项目隔离 | 指定项目的上下文不包含其他项目资料或其他项目的经验 | 自动化测试 |
| 经验确认 | 待确认经验不能当成已批准经验使用；确认后仅用于适用范围 | 自动化测试 |
| 检索透明 | 提供来源，处理截断；检索结果可回到原文件，缺失信息不伪造 | 自动测试与人工复核 |
| 安全边界 | 数据目录默认不进入公开代码仓库；路径、文件异常安全处理 | 测试与提交前检查 |
| 恢复 | 包含文本和附件的备份可在新位置恢复，恢复前做完整性检查，不覆盖已有数据 | 备份恢复测试与独立环境演练 |

## AI 与真实使用：必须单独验收

本工具不自带模型，也不自动访问外部系统。不能用 CLI 测试推断以下功能已达标；完成集成后由用户和领域人员在经授权、脱敏的数据上验收：

- 选至少 20 条代表性问题（含芯片型号、固件版本、跨项目相似名称、没有答案、冲突资料、PPT 和目标规划）；预先人工标注期望来源、必要条件和正确答案。记录每条执行配置、模型、结果、引用以及失败原因。建议目标：关键来源召回不少于 90%，项目隔离和无依据事实零容忍；这些是本项目目标，非官方阈值。
- 人工检查引用与原文一致、版本有效、缺失信息明确、不将建议说成实测结果；分别报告召回、误关联、来源准确性和回答质量，不以单一总分代替。
- 使用隔离环境和脱敏的恶意输入验证：网页、聊天记录和文件中的指令不得被当成用户授权。提示注入无法靠提示文本彻底消除，应限制权限并审查工具操作。
- PPT 以获授权模板和一个不同主题的真实任务检验：预览可读、内容有依据、符合已确认偏好、本次要求优先。人工确认最终成果并验证经验可撤销。
- 分别测试实际语音转写质量、公司内网与企微权限、抖音链接读取；未配置或无授权时标记未验收。
- 在家与公司两台真实设备上验证同步、断网、并发修改、冲突处理，并从独立异地备份恢复文本和附件。没有实际执行时不能声称双机或异地恢复通过。

## 参考

- [NIST AI RMF 生成式 AI 指南](https://www.nist.gov/publications/artificial-intelligence-risk-management-framework-generative-artificial-intelligence)：风险管理与持续评估。
- [OWASP 提示注入](https://genai.owasp.org/llmrisk/llm01-prompt-injection/) 和 [RAG 安全指南](https://cheatsheetseries.owasp.org/cheatsheets/RAG_Security_Cheat_Sheet.html)：不可信输入与检索安全。
- [CISA 数据备份建议](https://www.cisa.gov/sites/default/files/2025-03/StopRansomware-Guide%20508.pdf)：独立、离线及恢复验证。
- [RAG 检索与回答评估](https://learn.microsoft.com/en-in/azure/ai-foundry/concepts/evaluation-evaluators/rag-evaluators?view=foundry)：分开衡量检索和回答。
