# 本地与远程转写（试用版）

## 已实现和限制

本项目可调用本机安装的 douyin-insight 内置 faster-whisper 引擎，将本地音频或视频转成带时间戳的 JSON，并保存到所选数据目录的 `transcripts/`。它不会自动下载模型，不会自动上传音视频或调用大模型总结；在 Codex 中要求其读取逐字稿、按项目整理即可。对会议文字等可直接用原有 `intake --type text` 或 `file`，不需要转写。

本机已在 12 GB NVIDIA 显卡、small 模型上用合成语音完成一次 CUDA 转写。电脑上的技能目录、Python、显卡和模型路径可能因设备而异，首次使用先确认。`--device cuda` 无法调用显卡时会失败；不会悄悄按 CPU 报称 GPU 成功。允许用户明确选择 `--device cpu` 或 `auto`。

## 本机操作

1. 用 Codex 打开本项目，初始化自己的数据区，并创建相应项目。
2. 告诉 Codex：“把这个文件用本机显卡转写，关联到我的项目，再根据逐字稿整理会议纪要；不确定的信息标出来。”提供具体文件路径。若界面允许添加附件，也可以先提供附件，再由 Codex 确认本机实际路径。
3. 本机可用的 Python 及命令示例：

```powershell
& 'D:/AI_tools/douyin-insight/.venv/Scripts/python.exe' -B transcribe_local.py 'D:/path/meeting.mp4' --data 'D:/path/my-data' --project chip-a --device cuda
```

将示例路径及项目 ID 换成实际值。JSON 输出包含逐字稿、时间戳、模型、运行设备与来源文件名；指定项目时还生成可检索的机器转写文本，明确标为未核对。原文件不会删除；确认人名、数字和术语。缺少现有技能、模型或依赖时会给出错误，不自动下载。

## 抖音链接

在安装并可用的 douyin-insight 技能环境中，把公开作品链接交给 Codex，要求“按抖音技能获取并转写，再将逐字稿整理进指定项目”。该技能使用它自己的已配置登录状态；遇到登录失效或验证码，需由你按技能说明处理。链接不保证可下载，无法处理时保留链接并报告失败。本项目没有内置抖音 API、Cookie 管理或远程链接下载；不要把 Cookie 放在代码仓库或任务队列中。

## 共享目录队列（试用，不是远程服务）

它只负责在双方都能访问的**同一个受控共享目录**中投递文件和处理一次任务，不建立网络、不安装后台服务、不自动唤醒电脑、不进行 Codex 总结或 GitHub 同步。文件、转写和状态以明文存在共享目录。请先配置只有授权人员能访问的加密传输通道与目录权限；不应使用公开 GitHub 仓库作为队列。公司电脑必须允许该传输。仅共享同一目录的假设，不代表已验证跨网络一致性。

生产电脑上须有项目副本和已初始化的个人数据目录，项目 ID 若指定必须在该数据目录已存在。

```powershell
# 发送方：提供共享目录在此电脑的路径
python transcription_queue.py --queue 'Z:/trusted-queue' submit 'D:/path/meeting.mp4' --project chip-a

# 显卡电脑：同一共享目录在此电脑的路径；手动处理一项
python transcription_queue.py --queue 'Z:/trusted-queue' work-once --data 'D:/path/my-data' --python 'D:/AI_tools/douyin-insight/.venv/Scripts/python.exe' --device cuda
```

返回任务编号。`pending/<编号>` 为等待；`processing/<编号>` 为已领取；`done/<编号>/transcript.json` 是结果，`failed/<编号>/result.json` 是错误，失败时原文件保留。处理结束后，发送方在共享目录读取结果，并请 Codex 做整理；GPU 电脑也会在其数据目录留下逐字稿。处理过程中断可能留下 `processing`，本版本不会自动重试；先排查是否仍有进程运行，再手动处理，不要同时重复运行同一任务。

本机用同一目录模拟发送端与处理端已验证 CUDA 任务成功；**跨两台真实电脑、断网恢复、并发共享、服务重启和后台轮询尚未验收**。真实远程使用前需要确认传输方案和两台机器的可用状态。GitHub 仓库目前公开，默认忽略 `data/`；同步知识仍需单独配置并审核可公开的内容，GitHub 不应承载音频或未授权的公司信息。
